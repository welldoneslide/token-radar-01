Token launch radar: ranks pre-token DeFi protocols by implied launch value, with farm plans. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

## What this does

The radar-5 model scores every protocol in the frozen DefiLlama snapshot and ranks a 200-row board (40 watchlist protocols with no token yet + 160 early). The multiple is a size curve fitted on 128 token-bearing comparators (ln(mcap/TVL) on ln TVL) plus a staking-family offset where the family has at least 5 comparators — the curator-family offset was tested and dropped. Token odds come from a logistic fit on age and ln TVL (624 labeled protocols). Implied value = TVL x multiple x odds (an expected value), each row carries a P25–P75 range calibrated from held-out errors and a costed farm verdict (net of gas, $/hour). Every model term was tested held out (leave-one-out + three walk-forward cuts) and only terms that never worsen any test are kept — 2 of 13 value terms, 1 of 8 odds terms. Each row carries a 6-step, category-specific farm plan with no APY or airdrop promises. The dashboard in `dashboard/` is a static page (no framework, no network calls) with board, per-protocol detail, filter, search and sort; `output/board.json` and `output/dossier.json` are regenerated by `main.ts` (Node 22, standard library only).

Validated locally (20 Nov 2026): board 200 rows, watchlist 40/40 covered, implied values strictly descending, dashboard 51,696 bytes, 3 screenshots at 1280x800. Held-out value miss x3.39 vs flat x5.07; token-odds Brier 0.2156 vs base rate 0.2486; P25–P75 range covers 50.0% held out, as stated; farm verdicts 0 worth / 6 marginal / 194 skip (best $6.73/h, bar $25/h); 23 rows use a staking-family offset, 0 use a global fallback. See `BUILD-NOTES.md`, `BUILD-REPORT.md` and `EVALUATION-v4.md` for the formula, the computed multiples and all validation results.
