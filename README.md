Token launch radar: ranks pre-token DeFi protocols by implied launch value, with farm plans. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

## What this does

The radar-2 model scores every protocol in the frozen DefiLlama snapshot and ranks a 200-row board (40 watchlist protocols with no token yet + 160 early). Implied value = TVL x category multiple (median market-cap/TVL of tokenized peers in the same category, global median 0.2138 as fallback) x growth x maturity. Each row carries a 6-step, category-specific farm plan with no APY or airdrop promises. The dashboard in `dashboard/` is a static page (no framework, no network calls) with board, per-protocol detail, filter, search and sort; `output/board.json` and `output/dossier.json` are regenerated by `main.ts` (Node 22, standard library only).

Validated locally (19 Nov 2026): board 200 rows, watchlist 40/40 covered, implied values strictly descending, dashboard 35,281 bytes, 3 screenshots at 1280x800. See `BUILD-NOTES.md` and `BUILD-REPORT.md` for the formula, the computed multiples and all validation results.
