Token launch radar: ranks pre-token DeFi protocols by implied launch value, with farm plans. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

## What this does

The radar-3 model scores every protocol in the frozen DefiLlama snapshot and ranks a 200-row board (40 watchlist protocols with no token yet + 160 early). Implied value = TVL x multiple x growth x maturity, where the multiple is the category median where the category has at least 3 tokenized peers, the family median (curator or staking families, at least 5 comparators) where it does not, and the global median 0.2138 only as a last resort. Each row carries a 6-step, category-specific farm plan with no APY or airdrop promises. The dashboard in `dashboard/` is a static page (no framework, no network calls) with board, per-protocol detail, filter, search and sort; `output/board.json` and `output/dossier.json` are regenerated by `main.ts` (Node 22, standard library only).

Validated locally (20 Nov 2026): board 200 rows, watchlist 40/40 covered, implied values strictly descending, dashboard 37,122 bytes, 3 screenshots at 1280x800. Only 38 of 200 rows still use the global fallback (8 of 40 watchlist); 51 rows use a family median. See `BUILD-NOTES.md`, `BUILD-REPORT.md` and `EVALUATION-v2.md` for the formula, the computed multiples and all validation results.
